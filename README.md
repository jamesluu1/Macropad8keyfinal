# Macropad8keyfinal
Macropad8key Stardance Challenge
This is an 8 key macropad intended to assist you in functions like copy paste or whatever you prefer. 
It utilises 8 cherry mx keys, a fully 3d printed case running on Seeedstudio Xiao RP2040

PARTS TO MAKE THIS
- 8 cherry Mx switches
- 8 DSA keycaps
- 4 M3x16mm SHCS Bolts
- 8 1N4148 DO-35 Diodes.
- 1 XIAO RP2040
- 1 Case (2 printed parts, the top and the base)
